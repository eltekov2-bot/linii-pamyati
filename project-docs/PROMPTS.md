# Ключевые задания для создания проекта

Ниже — компактное описание использованных инструкций и логики работы, без выдачи синтетических сведений за исторические факты.

## 1. План

> Создай учебный генеалогический мини-продукт для самостоятельного исследователя. Пользователь должен найти персону, увидеть отдельные утверждения и их источники, отличить подтверждённые сведения от гипотез, сохранить заметку. Данные полностью синтетические. Не добавляй регистрацию, оплату, внешний API или облачную базу. Опиши результат и тесты прежде, чем расширять функциональность.

## 2. Интерфейс

> Реализуй адаптивный статический сайт на русском языке. Разделы: обзор, персоны, источники, связи, о проекте. Визуальный стиль — современный архив: тёплая бумага, глубокий зелёный цвет, спокойная типографика. Сохраняй читаемость, клавиатурную навигацию и понятные пустые состояния.

## 3. Данные и правила

> Подготовь 10 вымышленных персон и 8 вымышленных источников с внутренними ID. Каждое утверждение ссылается на один или несколько источников. Сокращённое имя «Ирина Н.» в списке 1946 года считать косвенным указанием, а не доказанной дочерью. В интерфейсе явно маркировать эту связь гипотезой. Шифры маркировать как учебные.

## 4. Проверка

> Проверь сценарии: поиск существующего и отсутствующего имени, фильтр статуса, фильтр типа источника, переход из персоны в документ, сохранение заметки, экспорт CSV, просмотр связей и мобильную компоновку. Не утверждай, что проверен сценарий, который фактически не запускался.
