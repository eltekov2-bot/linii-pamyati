**Проверка данных:** десять уникальных идентификаторов персон, восемь уникальных идентификаторов источников. Все `sources` в утверждениях и все родственные ID должны вести к существующим записям.

## Планируемая итерация

**Проблема первой версии:** переход по вкладке менял данные, но оставлял пользователя у верхней границы страницы; содержимое раздела могло находиться ниже первого экрана.

**Исправление:** при переключении вкладки прокручивать к меню разделов. **Повторная проверка:** переключение «Персоны → Источники → Связи» и возврат к каталогу не должны терять введённые фильтры.
