# Паспорт выпускного проекта

**Название:** «Линии памяти — генеалогический помощник».

**Пользователь:** человек, который самостоятельно изучает историю семьи и проверяет архивные сведения.

**Проблема:** в отдельных документах, заметках и родословных версиях смешиваются установленные факты и предположения. Трудно быстро найти человека и понять, на каком документе основано утверждение.

**Цель:** создать маленький автономный инструмент, демонстрирующий путь «персона → утверждение → источник → проверка / заметка».

**Выбранный состав:** цифровой мини-продукт с необходимыми текстами интерфейса, паспортом задачи и отчётом-кейсом. Отдельное видео и отдельный пакет рекламных макетов не входят в состав. Декоративная архивная графика — часть интерфейса.

**Основной результат:** работающий статический сайт с пятью разделами: «Обзор», «Персоны», «Источники», «Связи», «О проекте».

**Главный пользовательский сценарий:** найти Ирину Лаптеву → увидеть отметку гипотезы → прочитать посемейный список 1946 года → понять, чего он не доказывает → сохранить заметку о дальнейшей проверке.

**Демонстрационные исходные данные:** 10 вымышленных персон, 8 вымышленных документов, 4 поколения, одна исследовательская гипотеза. Архивные шифры начинаются с `УЧЕБ.` и не претендуют на существование в реальных фондах.

## Критерии готовности

1. Сайт открывается из `index.html` в корне проекта без сборки и сервера.
2. Поиск `Ирина` оставляет одну персону; запрос `Несуществующий` показывает сообщение о пустой выдаче.
3. Фильтр «Есть гипотеза» показывает только Ирину, «Подтверждено» — остальных девять.
4. В карточке Ирины ясно объяснено, что принадлежность к семье не доказана.
5. Кнопка источника открывает именно список 1946 года, а кнопки персон возвращают к нужным людям.
6. Заметка сохраняется после закрытия и повторного открытия карточки в том же браузере.
7. CSV содержит только людей из текущей выдачи и открывается с русскими символами.
8. Интерфейс работает при отсутствии результатов и на узком экране.

## Источники правил и сведений

| Сведения | Источник | Статус |
|---|---|---|
| Состав результата, пакет для сдачи и необходимость итерации | Учебный PDF «NC1vc4. Итоговый проект», страницы 5–13 и 78–80 | Требования курса |
| Имена, родственные связи, годы, архивные тексты | Синтетический набор `app.js` | Вымышлено для учебной задачи |
| Правило «не выдавать гипотезу за подтверждённый факт» | Собственный критерий качества проекта | Методологическое правило |

**Ограничения:** данные нельзя использовать для настоящих генеалогических выводов. Сайт не редактирует справочник, не подключается к архивам и не синхронизирует заметки.
