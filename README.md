# Линии памяти — генеалогический помощник

Работающий учебный мини-продукт для выпускного проекта курса Zerocoder «Китайские нейросети 2.0».

Сайт помогает находить людей, изучать родственные связи, читать архивные основания и отличать подтверждённые утверждения от гипотез.

**Рабочий сайт:** https://eltekov2-bot.github.io/linii-pamyati/

**Репозиторий:** https://github.com/eltekov2-bot/linii-pamyati

**Все персоны, события, цитаты и архивные шифры вымышлены.** Это демонстрационные данные, не реальные исторические свидетельства.

## Возможности

- 10 персон, 4 поколения и 8 условных архивных источников;
- поиск людей и фильтрация по статусу;
- переходы между персоной, утверждением, источником и родственниками;
- отдельная маркировка неподтверждённого родства;
- локальные заметки в браузере (без синхронизации);
- выгрузка отфильтрованного каталога в CSV;
- адаптивное оформление для разных экранов.

## Как запустить

Откройте `index.html` в современном браузере. Никакой установки, сервера, базы данных и API-ключей не требуется.

## Публикация

Проект опубликован через **GitHub Pages** из ветки `main`, папка `/(root)`. Сайт открывается по ссылке выше без регистрации и установки программ. Файлы `index.html`, `styles.css` и `app.js` расположены в корне репозитория.

## Проверочный сценарий

1. В разделе «Персоны» выполните поиск `Ирина`.
2. Откройте её карточку: сведения помечены гипотезой.
3. Перейдите к посемейному списку 1946 года и прочитайте ограничение источника.
4. Вернитесь к карточке и сохраните заметку.
5. Проверьте пустой поиск и скачайте CSV.

## Файлы

- `index.html`, `styles.css`, `app.js` — само приложение.
- `project-docs/PROJECT_PASSPORT.md` — паспорт задания.
- `project-docs/CASE_REPORT.md` — краткий отчёт-кейс.
- `project-docs/TEST_CASES.md` — проверки и ожидаемые результаты.
- `project-docs/PROMPTS.md` — ключевые формулировки задания и правил.
- `tests/check-data.mjs` — автоматическая проверка целостности демонстрационных данных (запуск: `node tests/check-data.mjs`).

## Применение ИИ и ограничения

Сам сайт работает автономно и **не вызывает нейросети или внешние API**; ключей доступа нет. Использование конкретных китайских моделей в процессе создания этой версии не заявляется.

Данные каталога встроены в JavaScript. Через интерфейс нельзя добавить нового человека или документ; заметки сохраняются только в локальном хранилище браузера и могут быть удалены при очистке данных.
